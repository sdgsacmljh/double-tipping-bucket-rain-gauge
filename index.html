    工作原理：降水 → 脉冲 → 雨量

    降水 → 承水器 → 漏斗 → 上翻斗 → 汇集漏斗 → 节流管 → 计量翻斗 → 计数翻斗 → 磁钢 → 干簧管 → 电脉冲 → 累计雨量
